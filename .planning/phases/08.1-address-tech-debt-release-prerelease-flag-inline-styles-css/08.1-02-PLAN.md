Purpose: Phase 6 closed DIR-03 for the 15 scorecard properties. Planner decisions (no CONTEXT.md exists, so these are Claude's discretion and recorded here for traceability):
- PD-03: The settings color dot and the swatches use a NEW namespaced custom property `--memochron-swatch-color`, set with `setCssProps`, plus `background-color: var(--memochron-swatch-color)` in styles.css. They do NOT pass the background-color property to `setCssProps` directly. Evidence: `node_modules/eslint-plugin-obsidianmd/dist/lib/rules/noStaticStylesAssignment.js` (Case 3) reports any `setCssProps` key written as a quoted string literal that does not start with `--`. A multi-word property name needs quotes, so `npm run lint` would fail on it. Phase 6's `setCssProps({ color })` passes only because the bare identifier key is not a string literal. The custom property also keeps the painting decision in styles.css, where themes can override it.
- PD-04: Keep the property name `--event-color` and only swap the write mechanism to `setCssProps({ "--event-color": value })`. styles.css already consumes it, and the rule allows `--` keys.
- PD-05 (I1): KEEP `memochron-daily-note` on all three agenda render paths, and document it in styles.css as an intentionally unstyled theming hook. Evidence: commit e9bcbf2 introduced the class with an empty placeholder rule ("Keep the same background as regular events"). Commit cb6d42e ("good visuals") deliberately deleted that empty rule and kept the class. The class is the only selector that tells the Daily Note entry apart from calendar events, so removing it could break users' CSS snippets.
- PD-06: Delete both `.memochron-controls.calendar-hidden` rule blocks. No tracked TS file applies `calendar-hidden`: `git ls-files | xargs grep -l calendar-hidden` lists only styles.css and Phase 6 planning docs. `CalendarView.updateCalendarVisibility` toggles `memochron-hidden` instead. Keep the `.memochron-agenda.agenda-only` rule, which is still toggled.

Spec-less probe fallback: no REQUIREMENTS.md IDs exist for this phase, so the edge probe was skipped (visible skip). Prohibitions were recalled in-prompt. Visual parity cannot be automated here (the project bans new tests this milestone), so it is carried as a backstop truth and routes to `/gsd-verify-work` UAT.
