## Blocking findings

**DOC-01: unsatisfied.** `.planning/REQUIREMENTS.md:31` explicitly requires a failing lint to block the build.

`.github/workflows/lint.yml:6-10,27-28` runs lint on branch pushes and PRs. The independent tag workflow `.github/workflows/release.yml:3-6,25-28` installs dependencies and builds without lint; `package.json:8` also contains no lint prerequisite. No prerequisite enforcing the branch workflow's result exists in this release path.

**Close:** require successful lint in the release/build path before build → attestation → release. Verify a representative lint failure stops that path before artifacts are published; preserve beta non-draft prerelease and stable draft routing.

Popout-context violations are warning-level. `package.json:10` uses `eslint src/` without a zero-warning gate.

The fresh probes above demonstrate forbidden ungated logs pass and a bare-document violation remains non-fatal. This conflicts with Phase 5 success criterion 1 and the milestone's promise that these findings cannot recur undetected.

**Close:** make required violations fatal while retaining only the documented narrow developer-debug exceptions. Confirm forbidden calls fail, accepted debug-gated logging remains valid, and actual source lint/build succeed. Neither B1 nor B2 is covered by the accepted ical.js or timer exceptions.
